# 08 · رعد: خادم جلب البيانات

> **رعدٌ خادمٌ يجلب بيانات الطالب من نظام مؤسسته:** يدخل باسمه، ويقرأ ما أُذن له فيه، ثم يخرج ولا يُبقي شيئًا. عملُه القراءة لا الكتابة، والنقل لا الحفظ (ADR-020). وهو جزءٌ قائمٌ بذاته في المشروع، في مجلده `raad/`، وله هويته وصورته وصفحته.

## هويّته

| | |
|---|---|
| **الاسم** | رعد (Raad) |
| **الصفة** | خادم جلب البيانات |
| **المقرّ** | أمستردام، بجوار خوادم الكلية (من ملف المؤسسة) |
| **الصورة** | `raad/identity/avatar.svg`، وتُستبدل بوضع `avatar.png` في المجلد نفسه ([README](../raad/identity/README.md)) |
| **ما يفعله** | يدخل حين يطلب الطالب التحديث، ويقرأ الجدول والدرجات والحضور والاختبارات، ويعاود متمهّلًا إذا تعثّر النظام، ثم يخرج ويطوي الجلسة |
| **ما لا يفعله** | لا يحفظ كلمة مرورٍ ولا بيانات، ولا يكتب في النظام شيئًا، ولا يطرق صفحةً لم يُؤذن للحساب فيها |

## نصفاه

| النصف | المكان | العمل |
|---|---|---|
| **المحرك** `raad/engine` | المتصفح | المهمة، ومحاولاتها، والتمهّل، وكل خطوة |
| **الخادم** `raad/server` | Worker على Cloudflare | التوجيه، والحماية من الإساءة، والإيقاف والإعلان، وبثّ الخطوات، واستضافة موصّلات الفئة د |

## المهمة (Job)

```ts
interface Job {
  id: string;
  type: 'sync';
  state: 'queued' | 'running' | 'waiting_retry' | 'succeeded' | 'failed' | 'needs_input' | 'cancelled';
  attempt: number; maxAttempts: number;
  deadline: string;          // بعده لا تبدأ محاولة
  steps: StepEvent[];        // ما يراه الطالب
  result?: SyncSummary;      // عدد التغيّرات والمجالات، لا البيانات نفسها
  failure?: { kind: FailureKind; message: string };
}
```

```
queued ──▶ running ──▶ succeeded
              │  ▲
     عارض     │  │ بعد التمهّل
              ▼  │
          waiting_retry
              │
  انتهت المحاولات أو الوقت ──▶ failed
  كلمة مرور خاطئة ──────────▶ needs_input
  أوقفه صاحب المشروع ───────▶ failed (PAUSED)
```

## الخطوات (الشفافية)

كل خطوةٍ تُسجّل ساعة وقوعها، ويراها الطالب في **سطر رعد** بلغته:

| الخطوة | أين | ما يراه الطالب |
|---|---|---|
| `connect` | الجهاز | رعدٌ في طريقه إلى نظام الكلية… |
| `signin` | الخادم | يدخل إلى النظام باسمك… |
| `fetch` | الخادم، لكل صفحة | يقرأ الجدول والتنبيهات… / يقرأ الدرجات… |
| `signout` | الخادم | يخرج من النظام ويطوي الجلسة… |
| `extract` | الجهاز | يستخرج بياناتك على جهازك… |
| `merge` | الجهاز | يقابل الجديد بما سبق… |
| `save` | الجهاز | يشفّر بياناتك ويحفظها على جهازك… |
| `wait` | الجهاز | تعثّر النظام، فيعاود بعد 4 ثوانٍ… |

خطوات الخادم تصل مبثوثةً سطرًا سطرًا ([05-architecture.md](05-architecture.md))، فلا يُعرض للطالب إلا ما حدث فعلًا. والملاحظات المرافقة للخطوات رموزٌ وأسماء صفحات، لا بيانات شخصية.

## الأعطال وسياسة كلٍّ منها

| الصنف | أمثلة | سياسة رعد |
|---|---|---|
| **جلسة** | `SESSION_EXPIRED`، `NOT_AUTHORIZED` | جلسةٌ جديدة بعد ثانيتين |
| **عارض** | مهلة، 5xx، انقطاع البث | تمهّلٌ متزايدٌ بعشوائية: 2، 4، 8، 16، 30 ثانية حتى المهلة الكلية |
| **كثرة الطلبات** | 429 | دقيقةٌ ونيّف |
| **دخول** | كلمة مرور خاطئة، أو قُفل الرقم مؤقتًا | توقّفٌ فوري، ولا تكرار أبدًا، فالتكرار قد يقفل الحساب |
| **إيقاف** | `PAUSED` من صاحب المشروع | توقّفٌ، ويعرض التطبيق السبب |
| **غير متوقع** | صفحةٌ لم نعهدها، أو حجبٌ من جدار الكلية | توقّف، والحالة `failed` |

## الحدود

- مهمة تحديثٍ واحدة في كل وقت، و5 محاولات على الأكثر في 90 ثانية.
- التحديث التلقائي عند فتح التطبيق، إن مضى على البيانات ربع ساعة.
- لا تقلّ المسافة بين محاولتين عن ثانيتين.
- على الخادم: 300 طلب في الدقيقة لكل عنوان (شبكة الكلية الواحدة)، و6 لكل رقم جامعي، وخمس كلمات مرور خاطئة تُريح الرقم ربع ساعة.

## مفاتيح صاحب المشروع

من لوحة Cloudflare: Workers ← `ties-raad` ← Settings ← Variables. تعمل فورًا، وتبقى بعد كل نشر.

| المتغير | الأثر |
|---|---|
| `RAAD_PAUSED` = `1` | يوقف رعدًا للجميع. وهذا ما تَعِد به الشروط إن طلبت الكلية |
| `RAAD_MESSAGE_AR` / `EN` | سبب الإيقاف |
| `NOTICE_AR` / `EN` | إعلانٌ يظهر بطاقةً لكل الطلاب. يُحذف المتغير لإخفائه |

## لا عمل في الخلفية على الخادم

يحتاج حفظ كلمة المرور على الخادم، وهذا خلاف المبادئ. التذكيرات تأتي من **تصدير الجدول إلى تقويم الجوال**، والجديد يظهر في **«ما الجديد»** عند فتح التطبيق.

## إحصاءاته (مجهولة، وبإذن الطالب)

```ts
{ jobType, outcome, attempts, sessionResets, errorClasses: string[], durationMs, appVersion }
```

لا رقم جامعي، ولا اسم، ولا عنوان، ولا معاملات المهمة.
