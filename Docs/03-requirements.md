# 03 · المتطلبات

الرموز: **R** متطلب وظيفي، **N** متطلب غير وظيفي. الأولوية: **P0** للإصدار الأول، **P1** بعده مباشرة، **P2** لاحقاً.

## المتطلبات الوظيفية

### العرض

| # | المتطلب | الأولوية |
|---|---|---|
| R1 | ملف الطالب هو الجذر: الاسم، والرقم الجامعي، والبرنامج، والفصل الحالي، والإيقافات والمطلوب، والإعدادات | P0 |
| R2 | محاضرات اليوم وغداً والأسبوع، مع تمييز المحاضرة الحالية والتالية، وتقويم شهري للمحاضرات والاختبارات | P0 |
| R3 | صفحة لكل مادة تجمع كل ما يخصها: مواعيدها، وغيابها، ودرجتها، واختبارها، ورابط البلاك بورد إن وُجد | P0 |
| R4 | الغياب لكل مادة، مع حد قابل للضبط وتنبيه عند الاقتراب منه | P0 |
| R5 | الدرجات والمعدل وإحصاءات الفصل | P0 |
| R6 | جدول الاختبارات عند نشره | P0 |
| R7 | الإيقافات (Holds) والمهام المطلوبة والمرشد وبيانات التواصل | P0 |
| R8 | **صفحة "المزيد":** أي جدول أو حقل يكتشفه النظام ولا يعرفه يظهر هنا تلقائياً، ويختفي إذا اختفى من المصدر | P1 |
| R9 | الفصول السابقة: الدرجات والسجل الأكاديمي، إن أتاحها النظام | P2 |
| R10 | فعاليات الكلية والتقويم الأكاديمي، عبر "المزيد" أو كقسم مستقل عند توفره | P2 |

| R26 | **اكتشاف الصلاحيات** من قوائم النظام نفسه، دون تجربة صفحات غير معروفة | P1 |

## المتطلبات غير الوظيفية

| # | المتطلب | المعيار |
|---|---|---|
| N1 | الأداء | تظهر البيانات المحفوظة خلال أقل من 300 ملّي ثانية. حجم JS الأولي أقل من 60KB مضغوطاً |
| N2 | الموثوقية | 98% أو أكثر من التحديثات تنجح دون تدخل الطالب. لا تختفي بيانات بسبب فشل جزئي |
| N3 | العمل دون اتصال | الواجهة وآخر البيانات تعمل بلا إنترنت |
| N4 | الأمان | لا تخزين على السيرفر. CSP صارمة. لا سكربتات من مصادر خارجية |
| N5 | الخصوصية | تقليل البيانات إلى الحد الأدنى. لا تحليلات تتبّع. العدادات مجهولة واختيارية |
| N6 | سهولة الوصول | مطابقة WCAG 2.2 AA: تباين، وتركيز واضح، وقارئ شاشة، وأهداف لمس لا تقل عن 44px |
| N7 | اللغتان | كل النصوص من ملفات ترجمة، ولا نص ثابت داخل الكود. اتجاه RTL وLTR صحيح |
| N8 | الأجهزة | iOS Safari 16+، Android Chrome، iPad، والكمبيوتر. قابل للتثبيت كـ PWA |
| N9 | التكلفة | صفر في الخطة المجانية لـ Cloudflare |
| N10 | التهذيب مع المصدر | حدود طلبات، وانتظار متزايد بين المحاولات، و User-Agent يعرّف بالمشروع |
| N11 | قابلية الاستبدال | تغيير مصدر البيانات لا يمس الواجهة ولا نموذج البيانات |
| N12 | الصيانة | TypeScript، واختبارات على عينات حقيقية مُجهّلة، وتوثيق القرارات |

## خارج النطاق

- تطبيق أصلي في المتاجر.
- أي لغة غير العربية والإنجليزية.
- الدفع أو الرسوم كإجراء. العرض فقط ممكن إذا كان متاحاً.
- حسابات الدكاترة والموظفين.
