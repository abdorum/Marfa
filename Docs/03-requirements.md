# 03 · المتطلبات

الرموز: **R** متطلب وظيفي، **N** متطلب غير وظيفي. الأولوية: **P0** للنسخة 1، **P1** للنسخة 2، **P2** لاحقاً. التفاصيل في [خطة النسخة 1](%D8%AE%D8%B7%D8%A9%20%D8%A7%D9%84%D9%86%D8%B3%D8%AE%D8%A9%201.md).

## المتطلبات غير الوظيفية

| # | المتطلب | المعيار |
|---|---|---|
| N1 | الأداء | تظهر البيانات المحفوظة خلال أقل من 300 ملّي ثانية. حجم JS الأولي أقل من 60KB مضغوطاً |
| N2 | الموثوقية | 98% أو أكثر من التحديثات تنجح دون تدخل الطالب. لا تختفي بيانات بسبب فشل جزئي |
| N3 | العمل دون اتصال | الواجهة وآخر البيانات تعمل بلا إنترنت |
| N4 | الأمان | لا تخزين على السيرفر. CSP صارمة. لا سكربتات من مصادر خارجية |
| N5 | الخصوصية | تقليل البيانات إلى الحد الأدنى. لا تحليلات تتبّع. العدادات مجهولة واختيارية |
| N6 | سهولة الوصول | مطابقة WCAG 2.2 AA: تباين، وتركيز واضح، وقارئ شاشة، وأهداف لمس لا تقل عن 44px |
| N7 | اللغتان | كل النصوص من ملفات ترجمة، ولا نص ثابت داخل الكود. اتجاه RTL وLTR صحيح |
| N8 | الأجهزة | iOS Safari 16+، Android Chrome، iPad، والكمبيوتر. قابل للتثبيت كـ PWA |
| N9 | التكلفة | صفر في الخطة المجانية لـ Cloudflare |
| N10 | التهذيب مع المصدر | حدود طلبات، وانتظار متزايد بين المحاولات، و User-Agent يعرّف بالمشروع |
| N11 | الاستقلال عن المصدر | إضافة مصدر أو تبديله لا يمس الواجهة ولا نموذج البيانات. كل محوّل يجتاز اختبارات المطابقة نفسها |
| N12 | الصيانة | TypeScript، واختبارات على عينات حقيقية مُجهّلة، وتوثيق القرارات |

## خارج النطاق

- تطبيق أصلي في المتاجر.
- أي لغة غير العربية والإنجليزية.
- **أي إجراء يكتب في المصدر:** التسجيل، والحذف، والانسحاب، والدفع، والطلبات. العرض فقط.
- مقارنة الطالب بزملائه، والمنتديات، وتقييم الدكاترة.
- حسابات الدكاترة والموظفين.
