# 05 · المعمارية

> النواة لا تعرف مصدرًا، والواجهة لا تعرف محوّلًا، ورعدٌ جزءٌ قائمٌ بذاته. على هذا تقوم المعمارية السداسية (Ports & Adapters) في المشروع، والموقع كله صفحاتٌ ثابتة على Cloudflare، لا خادم له إلا خادم رعد.

## الصورة كاملة

```
┌──────────────────── المتصفح: موقع ثابت على Cloudflare Pages ────────────────────┐
│                                                                                 │
│  الواجهة (src/web)  ──▶  التطبيق (src/app)  ──▶  النواة (src/core)               │
│  البطاقات والشاشات        الدخول والتحديث          النموذج · الدمج · الأرشيف        │
│                           والخروج والتفضيلات        التغيّرات · الاشتقاقات · التقويم   │
│                                 │                                               │
│                                 ├──▶ منفذ المصدر ──▶ src/adapters/sources        │
│                                 │                    peoplesoft (د) · official (ب) · demo (أ) │
│                                 ├──▶ منفذ التخزين ─▶ IndexedDB + تشفير WebCrypto │
│                                 └──▶ منفذ رعد ─────▶ حالة خادم رعد              │
│                                                                                 │
│  محرك رعد (raad/engine): المهام، والمحاولات، والتمهّل، والخطوات                    │
└────────────────────────────────────┬────────────────────────────────────────────┘
                                     │ HTTPS، والخطوات تُبثّ سطرًا سطرًا
┌────────────────────────────────────▼────────────────────────────────┐
│ خادم رعد (raad/server): Worker في أمستردام                            │
│ التوجيه · الحماية من الإساءة · الإيقاف والإعلان · موصّلات المصادر       │
└────────────────────────────────────┬────────────────────────────────┘
                                     ▼
                              نظام المؤسسة
```

الفئات من أ إلى د مرتبة حسب المخاطرة، ومعرّفة في [20-adapters.md](20-adapters.md).

## المجلدات والطبقات

| المجلد | ما فيه | يعرف | لا يعرف |
|---|---|---|---|
| `src/core/` | النموذج الموحّد، والدمج، والأرشيف، والتغيّرات، والاشتقاقات، وملف التقويم | لا شيء خارجه | الشبكة، والمتصفح، وأي مصدر |
| `src/ports/` | العقود: المصدر، والتخزين والتشفير، وخادم رعد | النواة | أي تنفيذ |
| `src/app/` | التطبيق: الدخول، والتحديث، والخروج، والوضع التجريبي، والتفضيلات | النواة، والمنافذ، ومحرك رعد | Preact، والمتصفح، وأي محوّل بعينه |
| `src/adapters/sources/` | محوّلات المصادر، وسجلّها | المنافذ والنواة | الواجهة |
| `src/adapters/browser/` | محوّلات المتصفح: IndexedDB، والتشفير، وحالة رعد، والإحصاءات | المنافذ | الواجهة |
| `src/institutions/` | ملفات المؤسسات | النواة | — |
| `src/web/` | الواجهة: البطاقات والشاشات. هي المحوّل الذي يقود التطبيق | التطبيق والنواة | المحوّلات، إلا في `state.ts` |
| `raad/engine/` | محرك رعد: المهام، والمحاولات، والخطوات | — | أي مصدر |
| `raad/server/` | خادم رعد: التوجيه، والحماية، والبث، والإيقاف | منفذ الموصّل | أي مصدر، إلا في سجلّ الموصّلات |
| `raad/identity/` | صورة رعد، وتُستبدل بوضع صورةٍ في المجلد ([README](../raad/identity/README.md)) | — | — |

**نقطة التركيب واحدة:** `src/web/state.ts`. فيها وحدها يلتقي التطبيق بمحوّلات المتصفح والمصادر، وكل ما سواها يعرف العقود لا التنفيذ.

**القاعدة الذهبية:** الواجهة لا ترى إلا `Snapshot` و`Job` وملف المؤسسة.

## المنافذ

```ts
// src/ports/source.ts: يقرأ ما يستطيع ويعيده بالنموذج الموحّد.
interface StudentDataSource {
  manifest: AdapterManifest;   // الفئة، وما يقدّمه، وما يحتاجه، وصائنه، وللقراءة فقط
  sync(ctx: SourceContext): Promise<SyncResult>;
}

// src/ports/storage.ts: ما يُحفظ على الجهاز، وتشفيره.
interface KeyValueStore { get; set; del; clear }
interface Sealer { seal(value); open(sealed); reset() }

// src/ports/raad.ts: هل رعدٌ موقوف أو يستريح؟ وهل من إعلان؟
interface RaadServer { status(): Promise<ServerStatus | undefined> }

// src/ports/edge.ts: موصّل مصدرٍ من الفئة د يستضيفه خادم رعد.
interface EdgeConnector { id; parts; sync(userid, pwd, parts, emit); health() }
```

**مفردات المحاولة في النواة** (`src/core/attempt.ts`): الخطوات وأنواع الأعطال (`RaadError`، `StepEvent`، `AttemptContext`). يتكلّمها المنفذ وكل محوّل، ولا يعرف أحدٌ منهم محرك رعد. والمحرك يقرّر ما يُصنع بكل نوع.

**لا اعتماد دائري:** الموصّل يعرف منفذه (`src/ports/edge.ts`) لا خادم رعد. والخادم يبني موصّلاته من ملف المؤسسة (`raad/server/connectors.ts`)، ويعطيها تعريفه بنفسه (`USER_AGENT`).

**لا منفذ للكتابة، ولن يكون:** المنتج للعرض فقط (ADR-020).

## رعد: جزءٌ قائمٌ بذاته

**هويته:** خادم جلب البيانات. يدخل نظام المؤسسة باسم الطالب، ويقرأ ما أُذن له فيه، ثم يخرج ولا يُبقي شيئًا. له صفحته في التطبيق، وصورته في `raad/identity/`، وتفصيله في [08-bot-spec.md](08-bot-spec.md).

**نصفان:**

| النصف | المكان | العمل |
|---|---|---|
| المحرك `raad/engine` | المتصفح | المهمة ومحاولاتها، والتمهّل بين المحاولات، وتسجيل كل خطوة ليراها الطالب |
| الخادم `raad/server` | Worker على Cloudflare، في أمستردام | التوجيه، والحماية من الإساءة، والإيقاف والإعلان، والبث، واستضافة موصّلات المصادر من الفئة د |

### مسارات الخادم

| المسار | العمل |
|---|---|
| `GET /api/v1/status` | هل رعدٌ موقوف أو يستريح؟ وإعلان صاحب المشروع، وإصدار رعد ورقم النشر. لا يمسّ نظام المؤسسة |
| `GET /api/v1/health` | هل يصل الخادم إلى نظام المؤسسة؟ يفتح صفحة الدخول فقط، ويُحفظ جوابه دقيقة |
| `POST /api/v1/sync` | دخول، وقراءة الأجزاء المسموحة، وخروج. ويبثّ خطواته إن طُلب ذلك |
| `POST /api/v1/metrics` | إحصاءات مجهولة، إن وافق الطالب |

### بثّ الخطوات (الشفافية)

إذا أرسل التطبيق `Accept: application/x-ndjson` ردّ الخادم سطرًا لكل خطوة ساعة وقوعها، ثم سطرًا أخيرًا بالنتيجة:

```
{"t":"step","key":"signin","status":"start"}
{"t":"step","key":"signin","status":"ok","ms":1840}
{"t":"step","key":"fetch","status":"start","note":"grades"}
…
{"t":"done","status":200,"body":{"pages":{…},"errors":{},"log":[…],"fetchedAt":"…"}}
```

ثم يضيف التطبيق خطواته على الجهاز: الاستخراج، والمقابلة بما سبق، والتشفير والحفظ. وكل خطوةٍ يراها الطالب في سطر رعد بلغته. والخادم يجيب الطلب القديم بلا بثّ أيضًا، فلا ينكسر تطبيقٌ مثبّتٌ قبل التحديث.

### مفاتيح صاحب المشروع

متغيرات في لوحة Cloudflare للـ Worker، تبقى بعد كل نشر (`keep_vars`)، وتعمل فورًا دون تعديل كود:

| المتغير | الأثر |
|---|---|
| `RAAD_PAUSED=1` | يوقف كل تحديث، ويعرض التطبيق أن رعدًا موقوف |
| `RAAD_MESSAGE_AR` / `RAAD_MESSAGE_EN` | سبب الإيقاف بكلماتك |
| `NOTICE_AR` / `NOTICE_EN` | إعلانٌ يظهر بطاقةً لكل الطلاب |
| `RAAD_DISABLE_PAGES` | أجزاءٌ لا تُقرأ، دون نشر |
| `RAAD_STALE_MINUTES` | عمر البيانات قبل أن تحدّثها الأجهزة بنفسها |

## الصدق قبل الدقة

- **لكل صفحةٍ معالم** (`landmark` في `extract/dom.ts`): إن غابت فالصفحة ليست التي نعرفها، والنتيجة خطأ `PARSE` لا قائمةٌ فارغة.
- **ما رجع فارغًا بعد امتلاء** في الفصل نفسه (الجدول، والحضور، والدرجات) يُعدّ مشكوكًا فيه (`doubtful` في `src/core/snapshot.ts`): تبقى البيانات القديمة موسومةً بالقِدم، فلا يُقال للطالب إن محاضراته حُذفت.
- **رصيد الغياب** يُحسب على أقصر فصلٍ محتمل ما دامت نهايته مجهولة، ويُعرض مدًى.

## محوّل PeopleSoft: لماذا ينقسم

| الجزء | المكان | السبب |
|---|---|---|
| الجلسة والدخول والكوكيز (`edge/`) | خادم رعد، موصّلًا | المتصفح ممنوع من قراءة صفحات نطاق آخر (CORS) |
| استخراج البيانات من الصفحات والتحويل للنموذج | المتصفح | بيانات الطالب لا تُحلَّل على أي خادم |
| الصفحات المسموحة (`pages.ts`) | مشترك | مصدرٌ واحدٌ للحقيقة |

**التعرّف على المادة برمزها الكامل** (`normalizeCourseKey`): فلا تندمج مادتان، ويبقى النظري والعملي مكوّنين لمادة واحدة.

## المرونة: الاستخراج العام و«ما سوى ذلك»

المستخرجات المعروفة تحوّل ما نعرفه إلى النموذج الموحّد. والمستخرج العام يمرّ على كل صفحة، فيأخذ كل جدولٍ لا نعرفه ببصمةٍ ثابتة، ويعرضه في «ما سوى ذلك» كما هو. وترقية جدولٍ إلى بطاقةٍ كاملة تعديلٌ في `registry.json`، لا كتابة كود.

**طلب صفحةٍ غير مسموحة يقتل الجلسة.** فالقائمة المسموحة هي المصدر الوحيد لما يُجلب، وتجربة صفحةٍ جديدة تكون في جلسةٍ معزولة ([10-peoplesoft-notes.md](10-peoplesoft-notes.md)).

## ما يُحفظ على الجهاز

| المفتاح | المحتوى | مشفّر |
|---|---|---|
| `snapshot` | اللقطة: البيانات، والأرشيف، والتغيّرات | نعم |
| `credentials` | كلمة المرور، إن اختار الطالب «تذكّرني» | نعم |
| `demo:snapshot` | لقطة الوضع التجريبي، منفصلةً عن الحقيقية | نعم |
| `prefs` | اللغة، والمظهر، وحد الغياب، والبطاقات المخفية | لا، ولا بيانات شخصية فيها |
| `raad:jobs` | سجلّ عمل رعد: خطواته وأوقاتها | لا، ولا بيانات شخصية فيه |
| `sealer:key` | مفتاح AES-GCM، لا يُستخرج من المتصفح | — |

تسجيل الخروج يمحو كل شيء إلا التفضيلات.

## الاختبارات

| النوع | يغطي |
|---|---|
| النواة | الاشتقاقات، والتعارض، ورصيد الغياب، والدمج، والأرشيف، والتغيّرات، والترحيل، وملف التقويم |

| التطبيق | الدخول، والتشفير، والوضع التجريبي، والخروج، بمخزنٍ في الذاكرة وتشفير WebCrypto الحقيقي |

## الوضع التجريبي

محوّل `demo` يعرض طالبًا وهميًا كاملًا، فيه تعارضٌ مقصود وتاريخٌ قصير، لتظهر كل البطاقات. يُفتح من زرّ «جولةٌ ببياناتٍ وهمية» في شاشة الدخول، أو بالرابط `?demo`. ولا يمسّ بيانات جلسةٍ حقيقية على الجهاز نفسه.
