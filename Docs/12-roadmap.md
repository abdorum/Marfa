# 12 · خارطة الطريق

كل مرحلة لها **معيار خروج**، ولا ننتقل للتالية قبل تحققه.

**القيد الزمني الأهم:** فترة تسجيل المواد تبدأ **الأسبوع القادم**. هي فرصة لا تتكرر إلا مرة كل فصل لالتقاط تدفق التسجيل، ولإظهار قيمة التطبيق للطلاب في أكثر وقت يعانون فيه من النظام. لذلك رُتّبت المراحل حولها.

```
الآن ─────────── بداية التسجيل ─────── نهاية التسجيل ──── الحذف والإضافة ──── منتصف الفصل
 │ المرحلة 0-1-2    │ المرحلة 3 (التقاط)  │ المرحلة 4 (بناء)   │ تجربة التسجيل    │ المرحلة 5-6
 │ نواة + واجهة     │ تسجّل بنفسك وأسجّل │ تدفق التسجيل       │ على حسابك أولاً   │ تجربة أولى ثم الإدارة
 │ + نشر            │                    │                    │                  │
```
