# بوابة معلومات الطالب · Taleeb Portal

**عارضٌ عامٌّ لمعلومات الطالب، يقرأ من أي مصدر،** ويعرضها بطاقاتٍ واضحة على جهاز الطالب: الجدول، والغياب، والدرجات، والاختبارات، وما تغيّر. **للعرض وحده،** لا ينفّذ إجراءً.

يجلب البيانات **رعد**، خادم جلب البيانات: يدخل نظام المؤسسة باسم الطالب، ويقرأ، ثم يخرج ولا يُبقي شيئًا، ويُطلع الطالب على كل خطوة. وأول مؤسسةٍ يعمل فيها كلية البترجي الطبية. مشروعٌ طلابيٌّ مستقل.

الموقع: https://taleeb-portal.pages.dev · الرؤية والخطة: [Docs/](Docs/README.md) · التغييرات: [CHANGELOG.md](CHANGELOG.md)

## كيف يعمل

```
المتصفح (موقع ثابت)                                                   Cloudflare
 الواجهة ─▶ التطبيق ─▶ النواة                 POST /api/v1/sync       خادم رعد (Worker)
 بطاقات      حالات       نموذج موحّد ·    ──────────────────────▶     دخول · صفحات مسموحة · خروج
            الاستخدام    اشتقاقات         ◀── الخطوات تُبثّ سطرًا ──    حماية · إيقاف · إعلان
                │                                                         │
                ├─▶ المحوّلات (المصادر)                                    ▼
                └─▶ IndexedDB مشفّرة                               نظام المؤسسة
 محرك رعد: المهام والمحاولات والخطوات
```

المعمارية سداسية (Ports & Adapters)، وتفصيلها في [Docs/05-architecture.md](Docs/05-architecture.md).

| المجلد | ما فيه |
|---|---|
| `src/core/` | النواة: النموذج الموحّد، والدمج، والأرشيف، والتغيّرات، والاشتقاقات، وملف التقويم. لا تعرف مصدرًا ولا متصفحًا |
| `src/ports/` | العقود: المصدر، والتخزين والتشفير، وخادم رعد |
| `src/app/` | التطبيق: الدخول، والتحديث، والخروج، والوضع التجريبي. لا يعرف Preact |
| `src/adapters/sources/` | المحوّلات: `peoplesoft` (الفئة د)، و`official` (ب)، و`demo` (أ) |
| `src/adapters/browser/` | IndexedDB، والتشفير بـ WebCrypto، وحالة رعد، والإحصاءات |
| `src/institutions/` | ملفات المؤسسات: `bmc.ts` |
| `src/web/` | الواجهة: البطاقات والشاشات. ونقطة التركيب الوحيدة `state.ts` |
| `raad/` | رعد: `engine/` في المتصفح، و`server/` على Cloudflare، و`identity/` صورته، و`worker.ts` |
| `functions/api/v1/` | دالة Pages التي تمرّر `/api/v1/*` إلى خادم رعد |
| `test/` | النواة، ورعد، والمطابقة، وPeopleSoft على صفحاتٍ حقيقية مُجهّلة، والتطبيق |

**تحذيرٌ مهم:** طلب صفحةٍ غير مسموحة للطالب يُنهي جلسة PeopleSoft كلها. لا تضف صفحةً إلى `src/adapters/sources/peoplesoft/pages.ts` قبل التأكد أنها تفتح لحساب طالب.

## التشغيل محليًا

```bash
npm install
```

```bash
npm run dev
```

يفتح على http://localhost:5173، ومعه خادم رعد نفسه الذي يعمل على Cloudflare. وللعرض بلا حساب: زرّ «جولةٌ ببياناتٍ وهمية»، أو `/?demo`.

```bash
npm test
```

### التقاط صفحاتٍ حقيقية للاختبارات

افتح `http://localhost:5173/?capture` وسجّل الدخول. تُحفظ الصفحات في `test/fixtures/peoplesoft/` بعد استبدال الاسم والرقم الجامعي والبريد بقيمٍ وهمية، وترفض الأداة حفظ صفحةٍ بقي فيها شيءٌ منها. راجع الملفات قبل أي commit.

## النشر على Cloudflare (مجاني)

- **الموقع:** مشروع Pages باسم `taleeb-portal`، يبنيه Cloudflare من فرع `main` وينشره على https://taleeb-portal.pages.dev (الإعدادات في `wrangler.toml`).
- **خادم رعد:** Worker باسم `ties-raad` (`raad/`)، في أمستردام بجوار نظام الكلية، لأن جدار الكلية يرفض بعض الدول ([Docs/10-peoplesoft-notes.md](Docs/10-peoplesoft-notes.md)). كل دفعٍ إلى `main` ينشره، والموقع يصل إليه داخليًا وليس له رابطٌ عام. ولنشره يدويًا:

```bash
npm run deploy:raad
```

### إيقاف رعد والإعلان

من لوحة Cloudflare: Workers ← `ties-raad` ← Settings ← Variables. يعمل فورًا ويبقى بعد كل نشر:

| المتغير | الأثر |
|---|---|
| `RAAD_PAUSED` = `1` | يوقف كل تحديث، ويرى الطلاب أن رعدًا موقوف |
| `RAAD_MESSAGE_AR` / `RAAD_MESSAGE_EN` | سبب الإيقاف |
| `NOTICE_AR` / `NOTICE_EN` | إعلانٌ يظهر بطاقةً لكل الطلاب. احذف المتغير لإخفائه |

## إعدادات

- **صورة رعد:** ضعها في `raad/identity/` باسم `avatar.png` ([التفاصيل](raad/identity/README.md)).
- **الصور الرمزية للطلاب:** في `public/avatars/`، وتُدرج تلقائيًا عند التشغيل والبناء.
- **الأيقونات:** عدّل الأشكال في `tools/make-icons.cjs` ثم `npm run icons`.
- **المؤسسة:** `src/institutions/bmc.ts`: حدّ الغياب، وطول الفصل، ومقياس المعدل…
- **النصوص:** `src/web/i18n/ar.ts` و`en.ts`، بفصحى موجزة لا عُجمة فيها.
